## 🗺️ 推荐学习路径

1. **打基础**：测试体系 → 黑盒用例设计 → 接口用例设计 → SQL → Linux/Shell
2. **上自动化**：自动化测试框架设计 → 接口自动化 → UI/移动端自动化
3. **做工程**：CI/CD → 测试数据与环境治理 → 性能测试 → 稳定性与混沌工程
4. **建体系**：质量保障体系 → 测试平台系统设计 → 服务端核心知识
5. **追前沿**：AI 与大模型测试 → Agent 测试 → MCP 测试 → Agent 评测流水线
6. **考前冲刺**：面试高频速查卡 → 按专题刷模拟面试题库（先自己答再看参考答案）

## 如何使用

```bash
git clone https://github.com/OldWooood/Interview-Preparation.git
cd Interview-Preparation
```

- 在线查阅：直接点击上面的链接；
- 本地刷题：按 `01 → 06` 顺序阅读，最后用 `05-面试冲刺` 自测；
- 面试前突击：只看 [面试高频速查卡](05-面试冲刺/面试高频速查卡.md) + 对应专题的模拟面试。
