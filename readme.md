## 🗺️ 推荐学习路径

1. **打基础**：测试体系 → 黑盒用例设计 → 接口用例设计 → SQL → Linux/Shell
2. **上自动化**：自动化测试框架设计 → 接口自动化 → UI/移动端自动化
3. **做工程**：CI/CD → 测试数据与环境治理 → 性能测试 → 稳定性与混沌工程
4. **建体系**：质量保障体系 → 测试平台系统设计 → 服务端核心知识
5. **追前沿**：AI 与大模型测试 → 精准测试/流量回放

## 🔥 面试冲刺顺序（按频次）

1. 项目经历与框架设计（自动化测试框架设计）
2. 接口测试与用例设计（接口用例设计 + 接口自动化）
3. 手撕代码 + SQL（测试开发编程与手撕代码 + SQL）
4. 质量体系开放题（质量保障体系与测试策略）
5. 平台设计题（测试平台系统设计题）
6. AI 测试（AI与大模型测试 + Agent测试与智能体质量保障）
7. 服务端八股（服务端核心知识）
