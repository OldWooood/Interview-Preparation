## 第一轮：语言八股（Python）

### Q1 ⭐ Python 可变/不可变类型？深浅拷贝区别？

**答：**

> list/dict/set 可变，str/tuple/int 不可变。赋值是引用；浅拷贝（copy.copy）只复制第一层，嵌套对象仍共享；深拷贝（copy.deepcopy）递归复制，互不影响。
> 面试补充：函数默认参数不要用可变对象（`def f(x=[])` 会跨调用累积），这是实际踩过的坑。

### Q2 装饰器是什么？手写一个计时装饰器。

```python
import functools, time

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            print(f"{func.__name__} 耗时 {time.perf_counter() - start:.4f}s")
    return wrapper

@timer
def slow():
    time.sleep(1)
```

**要点：** `functools.wraps` 保留元信息；`finally` 保证异常也计时。

### Q3 ⭐ GIL 是什么？多线程、多进程、协程怎么选？

**答：**

> GIL 是 CPython 的全局解释器锁，同一时刻只有一个线程执行字节码。
> IO 密集用多线程或 asyncio（等待时释放 GIL）；CPU 密集用多进程（多核并行）。协程适合高并发 IO，单线程事件循环，开销最小。
> 自动化测试里：接口并发多用线程池或 pytest-xdist 多进程。

### Q4 生成器是什么？什么时候用？

**答：** 用 yield 惰性产出，不占内存。适合大数据遍历、日志逐行处理、流式读取。

```python
def read_logs(path):
    with open(path) as f:
        for line in f:
            yield line.rstrip()
```

### Q7 Python 的异常处理机制？上下文管理器？

**答：** try/except/else/finally；异常按继承链捕获，自定义异常继承 Exception。上下文管理器用 `__enter__/__exit__` 或 `@contextmanager`，保证资源释放（文件/连接/锁），比 try-finally 优雅。

### Q8 怎么排查 Python 内存泄漏？

**答：** 看对象增长（`tracemalloc`/`gc`）、循环引用（`gc.collect` 后仍增长）、全局缓存无上限、线程/连接未释放。用 `objgraph` 看引用链；测试中用长稳运行 + 内存曲线定位。

## 第二轮：Java 八股（Java 栈面试）

### Q9 ⭐ HashMap 原理？

**答：** 数组 + 链表 + 红黑树；默认负载因子 0.75，扩容翻倍；hash 扰动降低冲突；链表长度 ≥8 且数组 ≥64 转红黑树。并发场景用 ConcurrentHashMap（分段/CAS + synchronized）。

### Q10 线程池核心参数？

**答：** 核心线程数、最大线程数、队列、拒绝策略、空闲存活时间、线程工厂。执行顺序：核心 → 队列 → 最大 → 拒绝。不用 Executors 默认工厂（队列无界会 OOM）。

🔁 追问：测试怎么用线程池？→ 模拟并发（CountDownLatch 发令枪）、压测请求分发。

### Q11 CountDownLatch 和 CyclicBarrier 区别？

**答：** CountDownLatch 一等多，计数到 0 释放且不可重置（适合等待并发任务完成）；CyclicBarrier 多等一，相互等待可循环（适合多线程集合后同时开跑）。

### Q12 用两个线程交替打印 1-100（说思路 + 关键代码）。

```java
synchronized (lock) {
    while (num <= 100 && num % 2 != (odd ? 1 : 0)) lock.wait();
    if (num > 100) { lock.notifyAll(); return; }
    System.out.println(num++);
    lock.notifyAll();
}
```

要点：synchronized + wait/notifyAll + while 防虚假唤醒 + 退出条件要 notify 对方。

### Q13 Java GC 怎么排查频繁 Full GC？

**答：** `jstat -gcutil` 看频率与耗时 → jmap dump 堆 → MAT 找大对象/泄漏引用 → 常见原因：缓存无上限、大对象常驻、元空间泄漏、堆参数不合理。测试视角：长稳 + 监控 GC 曲线。

```python
def is_valid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
```

### Q16 最长无重复子串

```python
def length_of_longest_substring(s):
    left, best, window = 0, 0, set()
    for right, ch in enumerate(s):
        while ch in window:
            window.remove(s[left]); left += 1
        window.add(ch)
        best = max(best, right - left + 1)
    return best
```

### Q18 ⭐ 快排（含原地版）

```python
def quick_sort(nums):
    if len(nums) <= 1:
        return nums
    pivot = nums[len(nums) // 2]
    return (quick_sort([x for x in nums if x < pivot])
            + [x for x in nums if x == pivot]
            + quick_sort([x for x in nums if x > pivot]))
```

**追问：** 最坏复杂度与优化？→ 有序数组时 O(n²)；随机选 pivot / 三数取中。

### Q19 二分查找

```python
def binary_search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

### Q20 LRU 缓存

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.cap, self.data = capacity, OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key, value):
        if key in self.data:
            self.data.move_to_end(key)
        self.data[key] = value
        if len(self.data) > self.cap:
            self.data.popitem(last=False)
```

**追问：** 为什么 O(1)？→ 哈希 + 双向链表；OrderedDict 已内置。

### Q22 合并两个有序数组（原地）

```python
def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    while j >= 0:
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]; i -= 1
        else:
            nums1[k] = nums2[j]; j -= 1
        k -= 1
```

### Q26 限流器（令牌桶）

```python
import time, threading

class RateLimiter:
    def __init__(self, rate, capacity):
        self.rate, self.capacity = rate, capacity
        self.tokens, self.last = capacity, time.monotonic()
        self.lock = threading.Lock()

    def acquire(self):
        with self.lock:
            now = time.monotonic()
            self.tokens = min(self.capacity, self.tokens + (now - self.last) * self.rate)
            self.last = now
            if self.tokens >= 1:
                self.tokens -= 1
                return True
            return False
```

### Q27 重试装饰器（测试框架常用）

```python
import functools, time

def retry(times=3, delay=1, exceptions=(Exception,)):
    def deco(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for i in range(times):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last = e
                    if i < times - 1:
                        time.sleep(delay * 2 ** i)
            raise last
        return wrapper
    return deco
```

**追问：** 测试怎么验证重试逻辑？→ mock 前两次抛异常、第三次成功，断言调用次数与最终结果；再加必失败场景断言最终抛出。

### Q28 写一个 JSON Diff（忽略指定字段）

```python
def json_diff(old, new, path="", ignore=()):
    diffs = []
    if isinstance(old, dict) and isinstance(new, dict):
        for k in set(old) | set(new):
            if k in ignore:
                continue
            p = f"{path}.{k}" if path else k
            if k not in old:
                diffs.append((p, "<missing>", new[k]))
            elif k not in new:
                diffs.append((p, old[k], "<missing>"))
            else:
                diffs.extend(json_diff(old[k], new[k], p, ignore))
    elif isinstance(old, list) and isinstance(new, list):
        if len(old) != len(new):
            diffs.append((path, f"len={len(old)}", f"len={len(new)}"))
        for i, (a, b) in enumerate(zip(old, new)):
            diffs.extend(json_diff(a, b, f"{path}[{i}]", ignore))
    elif old != new:
        diffs.append((path, old, new))
    return diffs
```

### Q29 日志解析：统计 5xx 接口 Top10

```python
import re
from collections import Counter

def top_5xx(log_path, n=10):
    pattern = re.compile(r'"\w+ (?P<url>\S+) HTTP/[\d.]+" (?P<status>\d{3})')
    counter = Counter()
    with open(log_path) as f:
        for line in f:
            m = pattern.search(line)
            if m and m.group("status").startswith("5"):
                counter[m.group("url")] += 1
    return counter.most_common(n)
```
